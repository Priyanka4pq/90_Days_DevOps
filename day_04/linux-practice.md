
# Linux Practice - Processes and Services

## Process Checks

### 1. View all running processes

```bash
ps aux
```

**Sample Output:**

![Sample Output](image.png)

**Observation:** Displays all currently running processes.

---

### 2. Monitor processes in real time

```bash
top
```

**Observation:** Shows CPU usage, memory usage, and active processes.

---

## Service Checks

### 3. Check Docker service status

```bash
sudo systemctl status docker
```

**Sample Output :**

![Sample Output](image2)


**Observation:** Docker service is running successfully.

---

### 4. List active services

```bash
systemctl list-units --type=service --state=running
```

**Observation:** Lists all currently running system services.

---

## Log Checks

### 5. View Docker service logs

```bash
sudo journalctl -u docker
```

**Observation:** Displays logs generated by the Docker service.

---

### 6. View the last 50 log entries

```bash
sudo journalctl -n 50
```

**Observation:** Shows the latest 50 system log entries.

---

# Mini Troubleshooting

### Problem

Wanted to verify whether the Docker service was running.

### Steps Performed

1. Checked the service status using:

```bash
sudo systemctl status docker
```

2. Viewed service logs:

```bash
sudo journalctl -u docker
```

3. Verified running services:

```bash
systemctl list-units --type=service --state=running
```

### Result

Docker service was running correctly, and no critical errors were found in the logs.
